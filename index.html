🧭 問對問題 · 五情境

⏰ 開口前・下決定前・卡住時——先開一張卡
🌲 問題拆解
先問對問題，再解題
分類清晰／繁雜／複雜／混沌？ 人心市場＝複雜→小實驗，別硬分析
定義5W1H 盤事實。這問題本身問對了嗎？
拆解為什麼？×5　有重疊？有遺漏？ 「X具體指什麼？預設了什麼？」
押假說我的假說？什麼證據能推翻它？
反著想怎樣必敗？然後呢？再然後呢？
分類 → 定義 → 拆到底 → 押假說 → 反著想
🤝 談判說服
說服不是講理，是調度焦慮
讀焦慮他真正怕什麼？站他位置怎麼看？
藏焦慮我急，是他需要還是我焦慮？
謙遜問我真的不知道答案嗎？ 先承接，再問「你最在意的是？」
挑時機行動／間接／直接說？ 時機＞內容
讓他贏怎麼讓他覺得是「他說服了我」？
讀焦慮 → 藏焦慮 → 謙遜問 → 挑時機 → 讓他贏
📊 報告呈現
結論先行，理由分層，證據墊底
結論對方最關心什麼？我的答案一句話？
三點理由≤3，有重疊？有遺漏？
證據這是事實還是觀點？我怎麼知道的？
預答他會追問什麼？然後呢？ 5W1H 查完整度
行動為什麼是現在？下一步要他做什麼？
結論 → 三點 → 事實 → 預答 → 收在行動
⚛️ 第一性原理 × 馬斯克演算法
拆到最根本，五步順序不可顛倒
拆到底不可再拆的事實？哪些只是慣例？從零怎麼設計？
質疑誰提的要求？預設了什麼？
刪除刪掉最壞會怎樣？ 刪到想加回10%才夠狠
簡化在優化不該存在的東西嗎？矛盾能否兼得？
加速最後才自動化，太早＝機器做白工
拆到底 → 質疑 → 刪除 → 簡化 → 加速殿後自動化
💎 需要 vs 想要
要的不是電鑽，是牆上的洞
聽想要他說的是解法，還是問題本身？
挖需要為什麼要？拿到之後呢？ 往下挖兩層
三問為什麼要買？為什麼跟我？為什麼現在？
驗價值對方能量化、能驗收嗎？
賣信任賣產品，還是「非你不可」？ 求長期，不求當下
聽想要 → 挖需要 → 三問 → 驗價值 → 賣信任
🔤 5W1H　誰・何事・何時・何地・為何・如何
🏛️ 蘇格拉底六型　澄清・假設・證據・觀點・後果・問題本身
