✏️ 提問設計（BBT 四階段）
問題意識 ＝ BBT 句型 × 5W1H；模糊的感知 → 有結構有方向的提問
建構因為…我想要（目標）→ 但是…造成（落差）→ 因此…要如何（方向）
因為＝脈絡 Why/Where/When/Who；但是＝難題 What；因此＝方向 How
解構對象是誰？目的（背後動機）？問題本質（根源）？發生順序？
重構框內：如何/什麼/如果（無序）｜亮點：什麼→為什麼→如何（放大1%成功）｜破框：為什麼→如果→如何（挑戰假設、顛覆現狀）
AI協作把問題丟給AI：用三關鍵字改寫→找被忽略的亮點→扮演馬斯克等專家破框
AI給的都只是候選答案——判斷哪個問題值得追，是你的核心能力
金字塔收斂成 3 個重點，各配 2 個問題，排好提問順序
校態度我的問題落在「真誠×開放」象限嗎？
✗ 質疑責備（虛假×封閉）✗ 明知故問（虛假×開放）
選角色促進者：謙遜→共識→亮點｜創新者：觸發→歸零→亮點｜領導者：收重點→轉正向（Why改問How/What）→引決策
建構 → 解構 → 重構 → 組合 ↺ 循環（好問題會生出下一個問題）

📐 圖解二：問題感的刻意練習（覺察）
📐 圖解三：提問槓桿——三種角色的關鍵提問

🤝 談判說服
說服不是講理，是調度焦慮
讀焦慮他真正怕什麼？站他位置怎麼看？
藏焦慮我急，是他需要還是我焦慮？
謙遜問我真的不知道答案嗎？ 先承接，再問「你最在意的是？」
挑時機行動／間接／直接說？ 時機＞內容
讓他贏怎麼讓他覺得是「他說服了我」？
讀焦慮 → 藏焦慮 → 謙遜問 → 挑時機 → 讓他贏
📐 冰山：往下潛，才聽得到真話
📊 報告呈現
結論先行，理由分層，證據墊底
結論對方最關心什麼？我的答案一句話？
三點理由≤3，有重疊？有遺漏？
證據這是事實還是觀點？我怎麼知道的？
預答他會追問什麼？然後呢？ 5W1H 查完整度
行動為什麼是現在？下一步要他做什麼？
結論 → 三點 → 事實 → 預答 → 收在行動
📐 金字塔：由上而下說，由下而上撐
⚛️ 第一性原理 × 馬斯克演算法
拆到最根本，五步順序不可顛倒
拆到底不可再拆的事實？哪些只是慣例？從零怎麼設計？
質疑誰提的要求？預設了什麼？
刪除刪掉最壞會怎樣？ 刪到想加回10%才夠狠
簡化在優化不該存在的東西嗎？矛盾能否兼得？
加速最後才自動化，太早＝機器做白工
拆到底 → 質疑 → 刪除 → 簡化 → 加速殿後自動化
📐 先鑽到岩盤（第一性），再走五步流水線（演算法）
💎 需要 vs 想要
要的不是電鑽，是牆上的洞
聽想要他說的是解法，還是問題本身？
挖需要為什麼要？拿到之後呢？ 往下挖兩層
三問為什麼要買？為什麼跟我？為什麼現在？
驗價值對方能量化、能驗收嗎？
賣信任賣產品，還是「非你不可」？ 求長期，不求當下
聽想要 → 挖需要 → 三問 → 驗價值 → 賣信任
📐 往下挖兩層 ＋ 三環交集才成交
🧠 批判性思考
想什麼（八元素）→ 想得好不好（九標準）→ 誰在想（品格）
拆元素我漏了哪個零件？
目的・問題・資訊・推論・概念・假設・後果・觀點
量標準能舉例嗎？是真的嗎？和問題相關嗎？有另一面嗎？
清晰・準確・精確・相關・深度・廣度・邏輯・重要・公正
自調節我對自己的思考，思考過了嗎？什麼會推翻我的結論？
修品格我此刻缺的是謙遜還是勇氣？
謙遜・勇氣・同理・自主・誠實・堅毅・信理性・公正心
拆元素 → 量標準 → 自調節 → 修品格
📐 思維之輪：八元素轉動，九把尺衡量，品格作地基
⚠️ 三個易混點（看似衝突，其實分工）
① 為什麼×5 對事不對人——對事往下挖根因；對人連問「為什麼」有質問感，改問「怎麼／什麼」（正向提問力）
② 押假說 vs 謙遜提問——對事先押假說加速驗證，對人保持「真的不知道」；假說是拿來被推翻的，不是拿來守的
③ 🌲拆解 vs ✏️提問設計——🌲管自己解決問題，✏️管設計要問出口的問題；先拆清楚，再造問題
🧭 全流程串接：🌲 拆清楚 → ✏️ 造好問題 → 🤝 問出口 → 📊 說出去 → ⚛️ 動手改 → 🧠 驗收 → 💎 洞察沉澱
🔤 5W1H　誰・何事・何時・何地・為何・如何
🏛️ 蘇格拉底六型　澄清・假設・證據・觀點・後果・問題本身
